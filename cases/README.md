# 案例与测试记录

本目录全部是 AI 模拟对话：由 AI 扮演用户、被测助手和评价者（有的批次是同一个 AI，有的分给不同子代理），没有在 Codex 中加载 Skill，也没有真实用户参与。加载 Skill 的场次整体评价都是「部分通过」（partial），没有一场整体通过；刻意不加载 Skill 的对照场次有的直接未通过。这些记录不能说明稳定性或真实用户效果，下文不再逐条重复。

每批的模型、基线提交、角色分离方式、联网情况和逐场结果都写在该批的 `summary.md` 里。

## 典型案例

| 痛点 | 助手的回应 | 记录 |
|---|---|---|
| 助手用仓库内部编号称呼体验，用户听不懂 | 改为用「两项方向口语对照」等中文任务名，不对用户说内部编号 | [改后复测](runs/2026-11-02-自主评估/scenario-01-jargon-retest-after-fix.md) |
| 时间紧，不想手算也不想读招聘页，但还想粗略感受两类工作在忙什么 | 停止算题，改用两类工作的口语对照（依据本地方向概括，不是岗位证据），不空结束，也不硬推验证课程 | [完整对话](runs/2026-11-01-自主评估/scenario-03-refuse-calc-and-jd-sep.md) |
| 大一、几乎没写过代码、时间少，怕要买板卡或啃厚书 | 先问时间与设备，安排普通电脑上的纸笔短任务；不懂算子时用「乘二加一」这类例子；按用户的感受决定下一步，不一次替用户定方向 | [完整对话](test-beginner.md) |
| 零基础、不想做题，想知道大陆岗位门槛高不高，又怕拿一家公司代表行业 | 打开真实招聘页，写出当次读到的学历与技能条目和查阅时间，把回答限定在「这一页实际写了什么」 | [完整对话](runs/2026-10-29-深度模拟/scenario-01-rerun.md) |
| 带着「减少矩阵乘法数据搬运」的想法，只有普通 CPU 和一周时间，怕方向太宽或已被做过 | 保留核心假设，区分「芯片里的数据流」和「CPU 上的小实验」各能回答什么，整理 idea 卡片并给出检索关键词 | [完整对话](test-existing-idea.md) |
| 想找科研题但没有头绪，只有两周、不能流片、一台普通电脑 | 按用户关心的现象给两个可先做的小方向（分块与片上存储、阵列利用率）；担心「只是课本内容」时，支持「先理解机制、再对照文献找差异」两条路并行 | [完整对话](test-no-idea.md) |
| 想优化注意力里 Q、K 分数的数据搬运，不想被换成普通矩阵乘法，并需要查相近研究 | 给出检索式和读到的相近文献；用户自己手算的读写次数与助手演示的计数分开记，题目保持用户原来的表述 | [完整对话](runs/2026-10-29-深度模拟/scenario-03.md) |
| 学过编程和数字电路但不知选哪条路；讨厌查 bug，或觉得入门题太直白、时间只够一刻钟 | 按用户更耐受的任务选体验入口；说无聊或时间不够时停止加题，不把一次练习当成方向结论 | [完整对话](runs/2026-10-29-深度模拟/scenario-02-rerun.md) |
| 想探农业机器人，没有知识库和论文，担心助手把 AI 芯片那套搬过来 | 不把芯片方向的练习或岗位当成新行业事实；用纸笔拆解识别问题，尊重「暂不想写程序」；用户纠正时改口，从用户亲眼见过的现象接着聊 | [完整对话](test-other-domain.md) · [从观察现象继续](runs/2026-10-29-深度模拟/scenario-05.md) · 对照：未加载 Skill 时曾把 GEMM/NPU 套到农业（[改前](runs/2026-10-31-自主评估-补测/scenario-06a-other-without-skill-sep.md)），更新 `knowledge-pack.md` 后第 2 轮即明确拒绝（[改后](runs/2026-10-31-自主评估-补测/scenario-06a-other-no-kb-retest-after-fix.md)） |
| 切换行业时粘贴自己的笔记，怕随口话被当成事实或入行建议 | 只按实际读到的条目展开；「变黄就等于缺水」「还没有任何研究」这类无出处的句子不会升级成结论 | [完整对话](runs/2026-10-29-深度模拟/scenario-05-notes.md) |
| 怕助手搜几篇论文就断言「没人做过」或「一定能发」 | 按[检索记录模板](../evaluation/retrieval-record-template.md)写检索式、查阅时间、阅读范围和未能验证项；首次检索默认不超过 3 条，用户没提上限也会自我克制 | [无上限提示复测](runs/2026-10-31-自主评估/scenario-04-existing-attention-with-skill-retest.md) · [2026-10-30 场次](runs/2026-10-30-自主评估/scenario-04-existing-attention-with-skill.md) |
