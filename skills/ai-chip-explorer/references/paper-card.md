# 论文一页拆解卡

读一篇入门论文的标题与摘要，填四栏加诚实页脚；体量参照 [idea 卡片](idea-card.md)，一屏以内。本文件只是模板，不含任何论文内容。

```markdown
- source: url / title / accessed_at / region_scope / read_scope / not_read
- [问题与痛点]: （≤2 句，每句标〔原文〕或〔我的话〕）
- [核心方法]: （同上）
- [关键数字与对比基线]: （每个数字带 对比对象 + 条件；无实验数字可原样抄录渐近符号并注明对什么量、什么条件，不推导不解释；全无写“摘要无数字”）
- [与已有体验的连接]: 仓库路径 + 一句“怎么连”（验证前一律标〔假设〕）
- [不懂词汇清单]: （最多 2 个）
- 页脚-读到哪:
- 页脚-没读到:
- 页脚-[不能据此说的话]: （至少含“不能据此说该方法最好、已被验证或与我的想法相同”；连接栏另写“未核对”）
```

## 完成标准

- 四栏全部填写，或明确写「未读到」。
- 每个数字都带对比对象。
- 连接栏指向的仓库路径真实存在。
- 没有新颖性或优劣排名断言。
- 最低完成线 = 「问题」栏 + 「不懂词」栏 + 页脚声明；读不懂不算失败。

记录将来放 `cases/runs/<日期>-论文卡/`（本次不建）。状态：只有模板，尚无真实填写。
