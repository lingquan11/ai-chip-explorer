# AI 芯片方向探索与科研构思

为 AI 芯片方向的初学者提供一位对话伙伴：先了解你的背景和目标，再帮助你认识不同方向、尝试轻量任务，或围绕科研 idea 展开探索。默认面向中国大陆大学生；对话方法也可结合用户提供的其他行业资料使用。

**状态：第一版草稿。** 方向推荐、岗位描述和科研想法都需要结合个人情况及资料进一步验证。已开展初步角色扮演模拟；独立多轮测试与真实用户验证仍待完成。

## 可以做什么

- **认识方向**：先看简明全景，再通过对话探索自己的兴趣和条件。
- **体验方向**：尝试中文轻量任务，并在过程中逐步辨认哪些工作方式吸引你。
- **探索科研 idea**：从零寻找候选问题，或带着已有想法来讨论、查找相关研究和设计初步验证。
- **切换行业**：提供自己的文件、网页或论文链接，或要求 AI 在工具可用时查找资料。实际读取范围取决于运行环境。

输出是探索建议，不是就业预测、能力测评或科研创新性证明。涉及就业时应检查岗位所在地区和发布时间；文献检索有范围限制，找不到结果不等于无人研究。

## 开始使用

本项目优先面向 Codex；其他 agent 的兼容性尚未验证。下面是预期的用户级安装方法，**尚待在目标环境实测**：

1. 将本仓库中的 `skills/ai-chip-explorer` 文件夹复制到 Codex 用户级技能目录，保留 `SKILL.md` 和整个 `references` 文件夹。常见路径是 Windows 的 `%USERPROFILE%\.codex\skills\ai-chip-explorer` 或 macOS/Linux 的 `~/.codex/skills/ai-chip-explorer`；如设置了 `CODEX_HOME`，以该目录下的 `skills` 为准。
2. 如果目标目录已经存在同名技能，先核对内容，不要直接覆盖。
3. 重新打开 Codex 会话，让它重新发现技能；输入 `$ai-chip-explorer` 并描述需求。具体发现和调用效果需要在实际环境中验证。

初次对话可以直接说：

```text
$ai-chip-explorer 我是电子信息专业大一，对 AI 芯片感兴趣，但不清楚有哪些方向。请先帮我了解，再设计一个轻量体验。
```

也可以带着科研想法开始：

```text
$ai-chip-explorer 我关注矩阵计算的数据搬运，有一个初步想法：……请先了解我的基础和条件，再帮我分析它。
```

或者切换行业：

```text
$ai-chip-explorer 我想探索机器人领域，附件和链接是我准备的资料。请说明实际读到的内容，并帮我梳理方向。
```

## 对话会是什么样？

### 招聘页写清样本边界

一位零基础的大学生不想做题，想知道在中国大陆是不是都要很强的电路和数学，并提醒不要用一家公司代表行业。

助手在 2026-10-29 20:15（CST）打开本地地图里点名的招聘页，写出算子岗位的硕士要求，以及架构岗位里的硬件描述要求，并标明这些条目没有发布日期、样本是这一家公司。

[阅读完整对话](cases/runs/2026-10-29-深度模拟/scenario-01-rerun.md)

### 注意力文献和用户自己算出的分数分开

一位用户想打磨“减少注意力里 Q、K 分数的数据搬运”，要求不要改成普通矩阵乘法，并追问有没有检索。

助手给出检索式和查阅时间，列出三篇已打开摘要与引言开头的文献。用户自己算出的 11 和 17 被单独记下，助手演示的读写次数另列。

[阅读完整对话](cases/runs/2026-10-29-深度模拟/scenario-03.md)

### 虚构笔记里的无出处断言被放下

一位用户粘贴了自己编写的虚构温室笔记，要求只根据实际读到的内容说话。

助手列出读到的笔记，并放下三句没有出处的话：“变黄就等于缺水”，“直线花盆不需要定位”，以及“这个题目还没有任何研究”。
